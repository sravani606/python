# Simple Chat Application

A basic Python chatbot application that interacts with users using
simple text responses.

## Features

-   Greets users
-   Responds to common questions
-   Introduces itself
-   Exits when user types `bye`
-   Handles unknown inputs

## How to Run

``` bash
python chat_application.py
```

## Example

    You: hi
    Bot: Hi! How are you?

    You: what is your name
    Bot: My name is ChatBot.
