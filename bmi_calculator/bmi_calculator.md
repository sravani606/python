# BMI Calculator

A simple Python BMI Calculator project.

## Features

-   Takes weight in kilograms
-   Takes height in meters
-   Calculates BMI
-   Displays BMI category:
    -   Underweight
    -   Normal
    -   Overweight
    -   Obese

## How to Run

``` bash
python bmi_calculator.py
```
